# Roadmap

The requested complete game is a multi-milestone product. Only the first playable slice is the current deliverable; a few combat/presentation features are pulled forward to make it coherent.

| Milestone | Scope | Status |
| --- | --- | --- |
| 1 — Vertical slice | Flight, desert, helicopter, cannon, armor, damage, explosions, menu/debrief | Implemented; unit/build/Chromium flows pass |
| 2 — Combat foundation | Expanded AI roster, missiles, lock, scoring, destruction | A subset included in slice; full roster planned |
| 3 — Missions | Data-driven ten-mission campaign, objectives, scripting | One mission now; framework expansion planned |
| 4 — World | Desert, jungle, mountain, city, night | Procedural desert now; other biomes planned |
| 5 — Presentation | Layered VFX/audio, HUD, cinematics | Slice foundation; full polish planned |
| 6 — Progression | XP, credits, upgrades, garage, unlocks | Planned; only local best score/settings now |
| 7 — Boss | Obsidian carrier, phases, drones, cinematic defeat | Planned |
| 8 — Optimization | Hardware profiling, LOD, adaptive quality | Initial pooling/instancing; full profiling planned |
| 9 — Polish | Accessibility, transitions, balance, edge cases | Ongoing |
| 10 — Release | Browser/device matrix, deployment, final QA | Not release-certified |

## Next coherent increment
After playtesting flight and mission balance, externalize mission definitions and add one moving convoy event plus a radar objective. Do not build nine near-identical placeholder missions.
